Extract trending tech articles, developer profiles, author social handles (GitHub, Twitter, Website), tags, and engagement metrics from Dev.to.

Powered by the official Dev.to REST API: Fast, structured, zero browser overhead, zero proxy fees.

---

### Features
- **Author & Developer Leads:** Instant extraction of GitHub, Twitter, and website URLs.
- **Engagement Metrics:** Filter and sort by reactions, positive votes, comments, and reading time.
- **Tag Filtering:** Target specific topics like Python, JavaScript, AI, DevOps, React, and Web Development.
- **Pay-Per-Event:** Only $0.003 per extracted lead. Zero compute surcharges.

---

### Integrations
- **Google Sheets & Airtable:** Export developer leads for tech recruiting and content outreach.
- **Make & Zapier:** Trigger automated workflows when new viral tech posts appear.
- **n8n:** Custom developer intelligence pipelines.
